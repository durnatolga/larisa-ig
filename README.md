# Larisa Beauty Instagram içerikleri

- `YYYY-MM/` : Instagram'a gönderilen görseller (Metricool bu raw linklerden çeker)
- `sablonlar/` : HTML tasarım şablonları (1080x1350 gönderi, 1080x1920 story). Playwright + Chrome ile JPG'ye çevrilir.
- `gercek/` : Salonun gerçek iş fotoğrafları (önce/sonra, kirpik, tırnak). Sonuç gösteren içerikte SADECE bunlar kullanılır.
- `plan-log.json` : Planlanan tüm paylaşımlar (tekrarı önlemek için).

Marka: turkuaz (#0e5f5c / #1f8f8a) + altın (#d4af6a / #e9cf96), fontlar Lora (başlık) + Poppins (metin).
